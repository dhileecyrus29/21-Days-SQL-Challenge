## 🎯 Project Overview
The **Great Pizza Analytics Challenge** is a hands-on SQL mini-project designed to apply key SQL concepts learned during the **21 Days SQL Challenge**.  

As the data analyst for **IDC Pizza**, the goal is to transform raw sales data into **actionable business insights** using real-world SQL queries.

---

## 🧩 Objectives
- Explore and clean pizza sales data.  
- Analyze product performance and customer orders.  
- Compute key business metrics like total sales, category performance, and pricing trends.  
- Practice all major SQL concepts — from basic filtering to complex joins.

---

## 📂 Database Schema
The database consists of the following key tables:  
- **pizza_types** → Pizza type details and ingredients  
- **pizzas** → Individual pizza size and price data  
- **orders** → Order date and time  
- **order_details** → Pizza quantity and order-level details  

---

## 🪜 Project Phases

### **Phase 1: Foundation & Inspection**
- Retrieve unique pizza categories.  
- Replace missing ingredient values with `"Missing Data"`.  
- Identify pizzas missing a price.

### **Phase 2: Filtering & Exploration**
- Filter orders by specific dates and times.  
- Explore pizzas by size, price range, and name keywords.  
- Analyze order patterns using logical operators and conditions.

### **Phase 3: Sales Performance**
- Calculate total pizzas sold and average pizza price.  
- Derive total order values using JOINs and aggregation.  
- Find category-level sales performance and top-performing categories.  
- Identify pizzas never ordered using LEFT JOIN.  
- Compare pricing across sizes using SELF JOIN.

---

## 📘 SQL Concepts Practiced
- **Data Cleaning:** DISTINCT, COALESCE, IS NULL  
- **Filtering:** WHERE, LIKE, BETWEEN, IN, AND/OR  
- **Aggregation:** SUM, AVG, COUNT, HAVING  
- **Joins:** INNER, LEFT, RIGHT, SELF  
- **Ordering:** ORDER BY, LIMIT  
- **Business Insights:** Category-wise performance and pricing analysis  

---

## 🧠 Key Learnings
- Strengthened understanding of **data filtering and aggregation**.  
- Learned how to **join and relate multiple tables** to extract real business insights.  
- Practiced **data cleaning** techniques to handle missing or duplicate data.  
- Discovered how **SQL can drive decisions** through metrics like top-selling categories and product pricing.
